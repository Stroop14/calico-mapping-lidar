Silver King Mine

Do these steps in order.

Each tunnel is this same sequence. Steps 1–8 are CloudCompare. Steps 9–18 are this page. Step 19 is the same walk built on the computer when the LAS file is too large for the browser. If the file is already one LAS and the scans already share one coordinate system, start at step 9. The finished Silver King walk is here.

  1. Install CloudCompare.

    CloudCompare is the free program that lines the scans up. Download it from cloudcompare.org, install it, and open it.

  2. Open the scan files.

    1. In CloudCompare, click File, then Open.
    2. Select every LAS file from the scanner. Hold Ctrl to select more than one. Click Open.
    3. Each file becomes one row in the DB Tree, the list on the left. The checkbox on a row shows or hides that cloud. Click the name to select it. A selected name is highlighted.
    4. The mouse in the 3D view: hold the left button and drag to rotate. Hold the right button and drag to slide the view. Roll the wheel to zoom. This is the normal mouse. Step 6 changes it while a polygon is being drawn.

  3. See whether the scans already share one coordinate system.

    1. Check the box on every scan so all of them are drawn. CloudCompare gives each one a different color when the file has no color.
    2. Rotate and zoom until you can see the whole set.
    3. If the walls of both walks occupy the same place, and the two colors are mixed on the same wall, they already share a coordinate system. Go to step 6.
    4. If you see two separate tunnels, or one tunnel floating away from the other, they do not share a coordinate system. Do step 4, then step 5, then step 6.

  4. Line the shifted scan up on the overlap.

    1. In the DB Tree, click the name of the scan that is in the wrong place.
    2. Hold Ctrl and click the name of the scan that should stay put. Both names are highlighted.
    3. Click Tools, then Registration, then Align (point pairs picking).
    4. The first window assigns roles. Aligned is the cloud that will move. Reference is the cloud that will not move. Set the two drop-downs. If they are reversed, click Swap. Click OK.
    5. Both clouds are now in one view, and a window opens at the upper right. It has an Aligned table, a Reference table, a checkbox for each cloud, an align button, a reset button, a green check mark, and a red X.
    6. Uncheck Reference so only the cloud that moves is visible.
    7. Left-click a spot that also exists in the other scan: a corner, the end of a timber, a rock edge, a rail. A marker whose name starts with A is drawn, and a row is added to the Aligned table.
    8. Left-click at least three more spots on that same cloud, spread along the overlap. Four pairs hold better than three. The row order is the pair order. Write the order down if you will not remember it: first spot, second spot, third spot, fourth spot.
    9. Uncheck Aligned. Check Reference.
    10. Left-click those same physical spots, in the same order. The first click on this cloud must be the same place as the first A marker. Markers whose names start with R are added to the Reference table. The two tables need the same number of rows.
    11. Check both clouds.
    12. Click align. The moving cloud shifts. The window shows an RMS, the leftover mismatch, and an error on each row.
    13. If one row’s error is much larger than the others, click the X on that row in both tables, pick that pair again, and click align again.
    14. Leave fixed scale checked. Unchecking it rescales one scan. These files came from the same kind of instrument.
    15. Click the green check mark to keep the move. A report window opens. Close it. Clicking the red X throws the move away. Reset puts the moving cloud back where it was before this tool.
    16. Rotate the result. If the walls now occupy the same place, go to step 5. If they are close and still separated by a small gap, do the next three clicks.
    17. Click Tools, then Registration, then Fine registration (ICP).
    18. In that window, Data is the cloud that moves. CloudCompare draws it red. Model is the cloud that stays. CloudCompare draws it yellow. Click Swap if red and yellow are reversed.
    19. Set Final overlap to the percentage of the moving scan that covers the same tunnel as the scan that stays. When about half of the moving scan overlaps the other, type 50. The value already in the box is 100. At 100, CloudCompare treats every point of the moving scan as part of the same object, and a scan that only shares a section of the tunnel is shifted off that section.
    20. Leave Adjust scale unchecked. Click OK. Wait until the red cloud stops moving.

  5. Merge the two scans into one cloud.

    1. In the DB Tree, click one scan’s name.
    2. Hold Ctrl and click the other scan’s name. Both are highlighted.
    3. Click Edit, then Merge.
    4. A new row appears in the DB Tree. That row is the combined cloud. The two original scans are still in the list.
    5. Uncheck the two originals. Leave the new cloud checked. Steps 6, 7, and 8 use the new cloud. The originals stay on disk as the files you opened.

  6. Delete the points that are far from the tunnel.

    The command is Edit, then Segment. It draws a polygon on the screen and then deletes the points on one side of that polygon. A minecart and a person stay in the result because you include them inside the polygon.

    Tools, then Clean, then SOR filter is a different command. SOR deletes points whose distance to their neighbors is larger than the distances in the rest of the cloud. A person and a minecart are sparse next to a wall, so SOR removes them. This step does not use SOR.

    1. In the DB Tree, click the merged cloud so its name is highlighted. The original scans stay unchecked.
    2. Click Edit, then Segment. A toolbar is added at the upper right of the 3D view.
    3. Press the Space bar. The Pause segmentation button is down. Shortcut: Space. While that button is down, the mouse is the normal mouse: left button rotates, right button slides the view, wheel zooms. Turn the cloud until the tunnel is one group and the stray points are visibly far from it.
    4. Press the Space bar again. Pause is off. Left-clicks now add corners of a polygon. The right button no longer slides the view.
    5. The toolbar’s selection mode should be polygonal. The tooltip on that button says “Polygonal selection”. If it says rectangular, click the arrow next to it and choose polygonal, or press Tab.
    6. Left-click a corner out past the tunnel, with the walls, the ground, the ceiling, the minecart, and any person inside the shape you are drawing. Left-click the next corner. Repeat until the polygon surrounds the whole tunnel. Between clicks, the current edge follows the mouse.
    7. Right-click once. That closes the polygon. The right-click does not add a corner.
    8. Click the toolbar button whose tooltip is “Segment Inside”. The second line of the tooltip says “keep points inside”. Shortcut: I. Points outside the polygon vanish from the view. They are hidden. They are not deleted yet. The tool returns to pause, so the left button rotates again.
    9. Rotate the cloud. Look at both ends, the cart, and the people. If something that belongs in the tunnel is missing, click the button whose tooltip is “Reset segmentation” (“Clear segmentation”). The hidden points return. Press Space to leave pause, and draw a wider polygon.
    10. When the view shows the tunnel and the things in it, and the far points are hidden, click the trash-can button. The tooltip is “Confirm and delete hidden points”. Shortcut: Delete. CloudCompare deletes the hidden points and leaves one cloud.
    11. Escape cancels the tool and deletes nothing. Enter confirms a split into two clouds and does not delete the hidden points. For one cloud with the far points removed, use the trash-can button.

  7. Thin the cloud.

    1. Click the cloud that remains after step 6.
    2. Hover a point in the 3D view and read the coordinates in the status bar at the bottom. If those numbers are in the tens or hundreds, the file is in meters. If they are in the tens of thousands, the file is in millimeters.
    3. Click Edit, then Subsample.
    4. Set the method to Spatial. Random, Random (%), and Octree are the other methods in that list. Spatial is the method with a minimum distance between kept points.
    5. In the minimum-distance box, type 0.02 if the file is in meters. That is 2 centimeters. Type 20 if the file is in millimeters. A short drift comes out around a million points.
    6. Click OK. CloudCompare makes a new cloud and unchecks the one you subsampled. The new cloud is the one to save. The points that remain are a subset of the old points. They are not moved.

    The Silver King file used 0.0125 meters, which is 1.25 centimeters, and kept 13,657,307 points. Use 0.02 unless the machine can hold the finer cloud. This page thins again, in step 10, to about 2 centimeters and about 1.5 million points.

  8. Save a LAS file.

    1. Click the new, subsampled cloud so its name is highlighted.
    2. Click File, then Save.
    3. At the bottom of the save window, open the file-type list. Choose “LAS cloud (*.las)”. BIN is CloudCompare’s own format. LAZ is compressed. This page opens LAS. It does not open LAZ or BIN.
    4. Choose a folder and a file name. Click Save.
    5. If a second window asks for a LAS version, point format, or scale, leave the values that are already filled in and click OK.

    If the scanner gave you LAZ, open that LAZ in CloudCompare and save it again with the file type set to LAS cloud.

  9. Set the colors on this page, before the scan.

    Floor is the ground. Wall is the side of the tunnel. Roof is the ceiling, the rock above your head. Click each color box and pick the color.

    Floor the ground
    Wall the side of the tunnel
    Roof the ceiling

    Or use one photograph. Click the button, choose the picture, and the page sets the three colors from it. The bottom of the picture is the ground. The middle is the wall. The top is the ceiling.

    The scanner recorded shape. These colors are painted on afterward. Where a shaft or the end of an adit goes black, the scanner did not bring points back.

  10. Open the scan on this page.

    Drop the LAS file from step 8 on the box below, or click the box and choose the file. To practice on the combined Silver King scan, use the button under the box. The same file is also silver-king-combined.las.zip if you want it on your computer: unzip it, then drop the LAS file on the box.

    Wait until the tunnel is drawn. The camera is placed inside the tunnel. The scan stays in this browser. The server does not receive a copy. This page thins the cloud again to about 2 centimeters and about 1.5 million points.

    If the status line says the file is LAZ, return to step 8 and save LAS. If the tab stops responding or the browser closes, the file is too large for this page. Use step 19.

  11. Move through the scan.

    The same list stays on the screen inside the scan.

    1. W walks forward. S walks back. A steps left. D steps right.
    2. Hold Shift with those keys to go much faster.
    3. Drag with the left mouse button to turn your head.
    4. Click the picture once and the mouse looks for you. Press Esc when you want the normal mouse back.
    5. Drag with the right mouse button to slide sideways and up.
    6. Roll the mouse wheel to move in and out. Hold Shift and roll the wheel to move farther.
    7. On a phone, drag the left side of the screen to walk. Drag the right side to look. It is the same page and the same cloud. The phone draws larger dots so the walls meet. A desktop draws smaller dots so the detail shows.
    8. Press the [ key to make the dots smaller. Press the ] key to make them larger.

  12. Mark key points along the tunnel.

    1. Move to the place where the walk should start. Use step 11.
    2. Press the K key, or click the button labeled Key point. The first marker is orange.
    3. Move at least half a meter. Press K again. The page rejects a new key point closer than 0.4 meters to the previous one.
    4. Repeat along the tunnel. Markers between the first and the last are drawn pale.
    5. Undo removes the last key point.

  13. End the walk on the last point.

    Move to the last place the walk should include. Click End the walk. The page adds that position as the last key point if it is at least 0.4 meters from the previous one, then stores the path. The last marker is green. End the walk requires at least two key points. With only one, the button does not store a path.

  14. Play it.

    Press Play to watch the walk. Press Stop to stop. Press Reverse to swap the direction. Press Lamp to turn the headlamp off and on.

  15. Download the site.

    Click Download the site. The file is mine-walk.zip. The button checks that End the walk has been pressed and that the path has at least two points. If either check fails, the hint line in the walk tells you to end the walk first, and no zip is written.

  16. Unzip the download.

    Unzip mine-walk.zip. The folder holds index.html, cloud.js, three.min.js, and HOW.txt. That folder is the walk.

  17. Look at it on your computer.

    1. Open a terminal in that unzipped folder. On Windows, click the folder bar, type cmd, and press Enter. On a Mac, open Terminal, type cd, then a space, and drag the folder into the window.
    2. Run python3 -m http.server 8000. If the computer says python3 is missing, run python -m http.server 8000.
    3. Open http://localhost:8000/ in the browser.
    4. Press Play.

  18. Put it on the web.

    Upload the unzipped folder to the web host you already use. Desktop and phone open the same address. Press Another scan, at the top of the walk, to come back to this list and start over.

  19. If the browser cannot hold the file, do it on the computer.

    1. Download this zip of the program and unzip it. The folder is named calico-mapping-lidar-gh-pages.
    2. Install Python from python.org if the computer does not have it. On the Windows installer, check Add python.exe to PATH.
    3. Copy your LAS file and your photograph into that folder.
    4. Open a terminal in that folder, the same way as step 17.
    5. Run pip install numpy pillow. NumPy holds the point coordinates. Pillow opens the photograph. They are not part of the scan.
    6. Run python3 tools/mine-walk/make_walk.py yourscan.las --photos yourphoto.jpg --out site. Use the real file names. On Windows, if python3 is missing, use python instead of python3.
    7. One photograph is read in bands: the bottom is the ground, the middle is the wall, and the top is the ceiling. If you have a separate ground photo and a separate wall photo, run python3 tools/mine-walk/make_walk.py yourscan.las --floor ground.jpg --wall wall.jpg --out site.
    8. For a finer cloud like Silver King, add --cell 0.0125 before --out site.
    9. Run cd site, then python3 -m http.server 8000, then open http://localhost:8000/.
    10. Press Play. This program lays the path down the middle of the tunnel for you. The orange dot is the start. The green dot is the end. Reverse swaps the direction.
    11. Upload the site folder the same way as step 18.

  20. Or hand the same steps to Cursor.

    Grok 4.7 or Opus 5.5 can follow this. Paste it, and put your LAS file and your photograph in the folder with it.

    Build a walk-through of one mine LiDAR scan as one web page. Phone and desktop open the same page and the same cloud. Desktop point size is smaller. Phone point size is larger, so a thinned wall still reads as a surface.

CloudCompare, in this order:
1. File, Open. Open every LAS. In the 3D view, left-drag rotates, right-drag pans, the wheel zooms.
2. If the tunnels do not already occupy the same space: select both clouds. Tools, Registration, Align (point pairs picking). Aligned moves, Reference stays. Pick at least four of the same spots, in the same order, on each cloud. Click align, then the green check. Leave fixed scale checked. If a small gap remains: Tools, Registration, Fine registration (ICP). Data moves (red), Model stays (yellow). Set Final overlap to the percent of the moving scan that actually overlaps the other, often about 50 when the walks share half their length. Leave Adjust scale unchecked.
3. Select both clouds. Edit, Merge. Use the new cloud. Uncheck the originals.
4. Edit, Segment. Space pauses so you can rotate. Space again to draw. Left-click a polygon around the tunnel, including walls, ground, ceiling, a minecart, and any person. Right-click closes the polygon and does not add a vertex. Click Segment Inside (keep points inside). Click the trash-can button, Confirm and delete hidden points. Do not use Tools, Clean, SOR filter. SOR removes sparse objects such as a person or a cart.
5. Edit, Subsample. Method: Spatial. Minimum distance 0.02 if the coordinates are meters, or 20 if they are millimeters. File, Save. File type: LAS cloud (*.las). Not LAZ. Not BIN.

Then one web page:
6. Before the scan is loaded, set three colors: ground, wall, ceiling. One photo may set all three: bottom of the photo is ground, middle is wall, top is ceiling.
7. Load the LAS. The camera starts inside the tunnel.
8. W A S D moves. Shift is faster. Left drag looks. Right drag slides. Wheel moves in and out. On a phone, the left side of the screen walks and the right side looks.
9. K, or the Key point button, stores a station. Stations closer than 0.4 m are rejected. The first marker is orange. Middle markers are pale. End the walk stores the current position as the last station and turns it green. At least two stations are required.
10. Play runs the path. Download writes a zip of the site. The scan is not uploaded.
